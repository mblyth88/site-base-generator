# Meliora Site Base Generator

Single-file browser tool by Meliora Engineering: type a SEQ address and get a GIS site base (DXF, PDF, PNG, JSON) built from Queensland and council open data. Indicative only — verify by survey and BYDA before design.

Live: https://mblyth88.github.io/site-base-generator/

## Data in this repo
`data/seqwater/` holds Seqwater's published "Network and Easement" data (trunk mains and easements), tiled for the tool. Seqwater provides it for general information and early planning or design purposes only; alignments are approximate and works near Seqwater assets need Seqwater's consent. Property addresses in the source data are not included. Refresh it when Seqwater publishes a new release.
